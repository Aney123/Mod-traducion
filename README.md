# Pack Español de Iván para RimWorld 1.6

Versión disponible: **1.4.0**. Traducciones al español para mods de RimWorld 1.6.

**[Descargar el pack en ZIP](https://github.com/Aney123/Mod-traducion/raw/refs/heads/main/descargas/Pack_Espanol_Ivan_1.4.0_RimWorld_1.6.zip)**

## Instalación

1. Cierra RimWorld.
2. Descarga el ZIP y extrae la carpeta `Pack_Espanol_Ivan` dentro de la carpeta `Mods` del juego. Si tienes una versión anterior, sustituye su carpeta completa para evitar mezclar versiones.
3. Activa **Harmony** y **Auto Translation**, además de este pack.
4. Coloca **Pack Español de Iván** al final de la lista de mods activos.
5. Selecciona **Español** o **Español (Latinoamérica)** y reinicia el juego.

La estructura debe quedar como `Mods/Pack_Espanol_Ivan/About/About.xml`.

## Dependencias

- [Harmony en Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- [Auto Translation en Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3278005460)

El pack utiliza una caché local; no necesita un Gist. Los mods originales se instalan por separado.

## Contenido y compatibilidad

- 49.616 entradas de caché.
- 59.646 reglas para textos de definiciones.
- 1.668 reglas para textos del código.
- [Lista de los 297 mods con entradas en el pack](MODS_INCLUIDOS.txt).

Estos recuentos indican el contenido del pack, no garantizan una traducción completa de cada mod. Las reglas del código dependen de las versiones concretas de las DLL inspeccionadas y pueden necesitar una revisión cuando se actualicen los mods.

## Archivos del repositorio

- `descargas/`: ZIP original de la versión 1.4.0 y su checksum SHA-256.
- `Pack_Espanol_Ivan/`: contenido del mod, incluido el cargador compilado, los datos y el código fuente.
- `Pack_Espanol_Ivan/LEEME_INSTALACION.txt`: instrucciones y alcance de las comprobaciones incluidas en el archivo original.

Esta publicación conserva los archivos del ZIP entregado por su autor. Las pruebas documentadas en el pack usan simulaciones; esta publicación no se ha probado dentro de una partida de RimWorld.
